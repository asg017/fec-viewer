FEC Viewer

A desktop app for exploring .fec files, the electronic filings committees submit to the Federal Election Commission. Open a filing to browse its cover page, schedules and every itemized record.

Try it in your browser · Download for macOS / Windows · Source on GitHub

The browser demo runs the same native UI compiled to WebAssembly. Drop a .fec file on it; it's parsed entirely in your browser and never uploaded anywhere.

Built with libfec and GPUI. Not affiliated with the FEC.
